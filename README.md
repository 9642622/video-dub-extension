# Перевод видео — расширение для Chrome

Версия 0.4.5. Установка описана в файле УСТАНОВКА.txt.

Коротко: скачать архив (кнопка **Code → Download ZIP**), распаковать в постоянную
папку, открыть `chrome://extensions`, включить «Режим разработчика», нажать
«Загрузить распакованное расширение» и указать эту папку. Затем вписать ключи
в настройках расширения.
